## 1. 项目简介 (Introduction)
NX-HLB 是一个基于完全去中心化架构的网络辅助工具，专为 Nintendo Switch 异地局域网联机设计。
传统异地联机方案高度依赖复杂的软件层穿透，而 NX-HLB 致力于通过外接微控制器（如 ESP32-S3）与桌面端中枢，将本地局域网数据桥接至第三方虚拟局域网（如 Radmin VPN / ZeroTier），从而提供极简且安全的远程本地联机（LDN）体验。

## 2. 核心特性 (Core Features - v0.4.3 Stable)
- **企业级安全通信**：PC 与 ESP32 之间采用 HMAC-SHA256 签名验证与防重放机制，彻底杜绝局域网窃听与伪造指令。
- **全局密码保护**：首次启动强制设置密码，所有本地敏感数据（WiFi 预设、通信密钥）均在本地加密存储（PBKDF2 + 模拟 AES 算法）。
- **沉浸式交互终端**：内置独立控制台，支持中文输入，可直接发送串口调试指令，并实时接收硬件回传日志。
- **秒级环境自检**：启动时自动扫描小蓝盾与硬件环境，支持按 ESC 随时中断。
- **崩溃守护机制**：主程序意外退出时，守护进程自动接管并输出错误上下文，防止“僵尸进程”残留。

## 3. 快速开始 (Quick Start)

### 3.1 普通用户 (Windows 二进制版)
1. 前往本仓库的 Releases 页面，下载最新版本的压缩包（如 `NX-HLB_Desktop_v0.4.3.zip`）。
2. 将压缩包解压至任意目录（建议路径中不包含中文字符）。
3. 双击 `run.exe` 启动主控台。
4. **首次启动**：请根据提示设置一个全局安全密码（用于加密你的 WiFi 预设）。
5. 确保后台已运行虚拟局域网软件（如 Radmin VPN），在主控台按下 `[1]` 触发环境检测。

### 3.2 硬件端配对 (ESP32)
1. 将 ESP32 烧录本仓库配套的固件。
2. 在 PC 端主控台按下 `[5]` 导出安全密钥（一串 32 位字符）。
3. 打开 Arduino 串口监视器，输入 `/setkey <你的密钥>` 完成配对。硬件将自动重启并完成安全握手。

### 3.3 开发者 (源码运行)
1. 克隆本仓库并确保本地安装 Python 3.10+ 环境。
2. 在项目根目录执行命令：`python run.py`
3. 程序将自动拉起主控台与日志监控窗口。
