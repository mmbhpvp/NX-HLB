## 1. 项目简介 (Introduction)
NX-HLB 是一个基于完全去中心化架构的网络辅助工具，专为 Nintendo Switch 异地局域网联机设计。
传统异地联机方案高度依赖复杂的软件层穿透，而 NX-HLB 致力于通过外接微控制器（如 ESP32-S3）与桌面端中枢，将本地局域网数据桥接至第三方虚拟局域网（如 Radmin VPN / ZeroTier），从而提供极简且安全的远程本地联机（LDN）体验。

## 2. 桌面端核心特性 (Desktop Features - v0.1.3 Dev)
- 双进程架构：主控台（main）与实时数据日志监控（--log-window）完全分离，避免高频 IO 阻塞主线程。
- 环境自动检测：内置 30 秒轮询检测机制，支持通过空格键强制中断线程。
- 异步日志记录：在 log 目录下自动生成以时间戳命名的日志文件，详细记录输入指令、底层网络收发状态及异常回溯。
- 崩溃守护机制：主程序发生未捕获异常（Unhandled Exception）终止时，守护进程（run）将接管控制权，输出最后 20 行日志并阻断进程退出。
- 跨环境兼容：基于 sys.frozen 动态识别 Python 源码环境与 PyInstaller 二进制打包环境。

## 3. 快速开始 (Quick Start)

### 3.1 普通用户 (Windows 二进制版)
1. 前往本仓库的 Releases 页面，下载最新版本的压缩包（如 NX-HLB_Desktop_v0.1.3_Dev.zip）。
2. 将压缩包解压至任意目录（建议路径中不包含中文字符）。
3. 双击 run.exe 启动主控台（请勿直接双击 main.exe）。
4. 确保后台已运行虚拟局域网软件（如 Radmin VPN），在主控台按下 [1] 触发环境检测。

### 3.2 开发者 (源码运行)
1. 克隆本仓库并确保本地安装 Python 3.10+ 环境。
2. 在项目根目录执行命令：python run.py
3. 程序将自动拉起主控台与日志监控窗口。
